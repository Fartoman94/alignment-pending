## Before/after the visual overhaul pass (3D asset pack + 2-light setup + closer camera)

Before (procedural-capsule staff, single light, original camera zoom, same three scenarios, same hardware) vs. after that pass:

| Scenario | Before FPS avg | After FPS avg | Before draw calls | After draw calls | Before primitives | After primitives |
|---|---|---|---|---|---|---|
| Small | 55.8 | 56.0 | 76 | 185 | 2,438 | 5,293 |
| Mid-game (20 staff) | 60.0 | 60.0 | 356 | 575 | 832,358 | 12,129 |
| Stress (150 staff) | 59.2 | 60.0 | 2,176 | 2,953 | 6,226,838 | 45,017 |

FPS held steady or improved slightly across the board despite real materials, two lights instead of one, and real furniture geometry replacing flat-colored boxes. Draw calls went up moderately (more separate mesh parts per placed object). **Primitives went down dramatically** at every staff count, most dramatically under stress (6.2M → 45K, ~138x fewer) — the old `CapsuleMesh`-based placeholder bodies were higher-poly than the pack's actual low-poly authored character models, so this pass is a genuine rendering-cost improvement, not just a visual one, alongside looking substantially better. See `docs/art/VISUAL_OVERHAUL_REPORT.md` for the full before/after screenshots and design rationale.

## Before/after the production-kit integration pass (garage/office clutter, break room, safety_lab model, 30 character variants)

The headline numbers at the top of this file are **after** this pass — the first re-profile since a new `--headless --editor --quit` reimport also changed the reported hardware string (`AMD Radeon Graphics (renoir)` → `AMD Radeon 610M (raphael_mendocino)`, this environment's GPU driver info, not a code change). |---|---|---|---|---|---|---|

No meaningful regression — every scenario still holds at or near the 60 FPS target (CLAUDE.md's baseline), the largest average delta is 1.0 FPS on the stress scenario, well inside this profiler's own documented run-to-run noise (see the small scenario's own min FPS: 7.0 this run vs. 19.0 in an earlier run, same unmodified code — a scene-load transient this profiler's warmup window doesn't fully absorb, not evidence of a real regression). Draw calls and primitives rose in proportion to the new fixed-position set dressing added this pass (garage clutter, break-room furniture, office-tier architecture, a real `safety_lab` model) — all static, non-instanced meshes placed once at scene build, not per-frame cost. The character-variant expansion added zero rendering cost (same StaffAgent pipeline, same triangle budget per character, just more mesh choices at spawn time).
