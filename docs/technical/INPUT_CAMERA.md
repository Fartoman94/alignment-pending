# Input and camera

## Keyboard/mouse
- WASD / middle-drag: pan.
- Mouse wheel: zoom.
- Q/E: rotate 90° smoothly.
- R: object rotate while building.
- Space: pause.
- 1/2/3: speed tiers.
- Esc: back/cancel.
- F: focus selected.

## Camera
Orthographic by default, 35–45° elevation, 4 cardinal rotations. Smooth interpolation. Clamp to playable bounds. Do not replicate camera easing/constants from another title.

## Controller later
Left stick pan, triggers rotate, right stick cursor/inspection, bumpers zoom, radial build menu.
