# Roadmap

## Phase 0 — Foundation
Repository, boot scene, architecture, input, camera, UI shell, save skeleton, asset provenance.

## Phase 1 — Vertical Slice
One office, building, staff, compute, research, model train/evaluate/release, users/revenue, incidents, one rival, one regulator, 30–45 minute mini-campaign.

## Phase 2 — Core Simulation
Full economy, staff depth, research tree, pricing, deployments, media/trust, legal/regulation, board/investors, rivals, agents/autonomy.

## Phase 3 — Content
100+ incidents, multiple rival doctrines, act progression, datacenter layer, endings, tutorial, difficulty modes.

## Phase 4 — Polish
Art pass, animation, sound/music, accessibility, controller, performance, UX, localization readiness.

## Phase 5 — Shipping
Steam integration adapter, achievements, cloud-save compatibility plan, store build QA, crash logging strategy, demo, release candidate.

### Scope guard
No multiplayer, live LLM calls, mod workshop, mobile port, or console port before 1.0 unless schedule/budget materially changes.
