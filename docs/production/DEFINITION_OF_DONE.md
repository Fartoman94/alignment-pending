# Definition of Done

A feature is done only when:
1. Acceptance criteria are met.
2. Normal and failure paths tested.
3. Save/load impact handled.
4. UI communicates state and errors.
5. No new P0/P1 defects known.
6. Performance checked if feature is tick-heavy/visual-heavy.
7. Data/content validation updated if needed.
8. Accessibility impact considered.
9. Originality/provenance recorded for new player-facing assets.
10. Documentation/status updated.
