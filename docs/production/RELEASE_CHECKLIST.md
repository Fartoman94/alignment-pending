# Release checklist

## Code/build
- [ ] Godot version pinned and documented.
- [ ] Reproducible clean export.
- [ ] Debug cheats excluded/disabled from retail build.
- [ ] Zero open P0/P1 defects.
- [ ] Save migration suite green.
- [ ] Crash-on-boot tested on clean Windows/Linux environments.

## Content
- [ ] All final assets in provenance ledger.
- [ ] No placeholder copyrighted/system-dependent fonts accidentally bundled.
- [ ] No real-world marks/likenesses in fiction or screenshots.
- [ ] Localization overflow pass.
- [ ] Audio mastering pass and loop audit.

## Legal/platform
- [ ] Final title trademark clearance.
- [ ] Steam content survey completed accurately.
- [ ] AI-assisted shipped content disclosed if required by current rules.
- [ ] Privacy policy only if telemetry/account data actually requires it.
- [ ] Third-party notices complete.

## Store
- [ ] Capsules/icons original.
- [ ] Trailer uses cleared music/assets.
- [ ] Screenshots match actual build.
- [ ] System requirements measured, not guessed.
