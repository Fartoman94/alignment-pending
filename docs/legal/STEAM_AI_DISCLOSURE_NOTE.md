# Steam AI-content disclosure note

Steam's current Content Survey distinguishes AI used merely for development efficiency from AI-assisted content that actually ships and is consumed by players. If AI-assisted artwork, sound, narrative, localization or other player-facing content ships, describe it accurately in the survey. Live-generated AI has additional safeguard requirements.

Project policy: gameplay should work fully offline and **not require live generative AI**. This reduces operational/legal complexity.

Before submission, re-check the current Steamworks rules because platform policies can change.
